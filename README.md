# מעקב ביוץ

אפליקציית ווב (PWA) למעקב אחרי מחזור וביוץ. היא בעברית, עובדת בטלפון, ואפשר להשתמש בה גם בלי אינטרנט. כל המידע נשמר רק במכשיר (IndexedDB), בלי שרת ובלי התחברות.

## מה יש באפליקציה
- **לוח שנה לחיץ**: וסת, וסת צפויה, חלון פוריות, הימים הכי פוריים, ביוץ צפוי או מאומת, בדיקות וניסיונות.
- **צילום בדיקת ביוץ**: אפשר לצלם ישירות מהמצלמה או לבחור מהגלריה, ולשמור כמה בדיקות ביום. לכל בדיקה בוחרים תוצאה: שלילי, חלש, חיובי או שיא.
- **השוואת בדיקות**: כל התמונות של המחזור מוצגות בשורה אחת לפי סדר הימים.
- **היסטוריה**: הזנת מחזורים וביוצים קודמים, עם ממוצעים, טווח אורכי מחזור ושלב לוטאלי.
- **חישוב חלון הפוריות**: לפי אורך המחזור הממוצע (עד 6 מחזורים אחרונים) והשלב הלוטאלי. בדיקה חיובית מעדכנת את התחזית, והביוץ צפוי יום אחריה.
- **ניסיונות**: תיעוד עם שעה, וספירה של כמה ניסיונות היו בחלון הפוריות.
- **גיבוי**: ייצוא וייבוא של כל המידע, כולל התמונות, לקובץ JSON.

## הרצה מקומית
```
python3 -m http.server 8000
```
ואז לפתוח http://localhost:8000

## העלאה ל-GitHub Pages
Settings ← Pages ← Source: "Deploy from a branch", לבחור את הענף ואת התיקייה `/ (root)`.

## התקנה על הטלפון
- **אייפון (Safari)**: כפתור השיתוף ← "הוסף למסך הבית".
- **אנדרואיד (Chrome)**: תפריט ⋮ ← "התקן אפליקציה".

> התחזיות הן הערכה סטטיסטית בלבד ואינן ייעוץ רפואי.
